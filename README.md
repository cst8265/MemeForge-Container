# MemeForge Container

## Objective
MemeForge is about to be containerized. A teammate wrote a `Dockerfile` and a `docker-compose.yml`. Both "work" — the image builds and the site comes up — which is exactly why nobody has looked closely at them. You will review both files the way you would review a pull request, explain what an attacker gains from each problem, and rewrite them so the container follows least privilege.
